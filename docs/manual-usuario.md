# Manual de usuario

> Documento en construcción. Se completa a medida que se implementan los módulos
> (reservas, check-in/out, consumos, reportes).

## Perfiles de usuario

- **Recepción:** gestiona reservas, check-in / check-out y consumos.
- **Administración:** habitaciones, tarifas, temporadas, promociones y usuarios.
- **Gerencia:** acceso a reportes y dashboard.
- **Housekeeping:** estado de limpieza de las habitaciones.
- **Huésped:** reserva online desde el portal público.

## Módulos (se documentan al implementarse)

1. Reservas y estadías
2. Check-in / Check-out + facturación
3. Consumos y servicios
4. Gestión de huéspedes
5. Administración
6. Reportes
